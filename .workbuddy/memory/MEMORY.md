# 项目长期记忆

## 项目概述
- **项目名称**：汉白玉智慧会议桌（智能产品应用部分）
- **角色**：我们只做软件 + 电子集成，桌子本体和材料加工由客户公司负责
- **客户方联系人**：四O（采购），负责最终验收和点头，是"自己人"
- **当前阶段**：软件骨架已完成，等待与客户确认后启动硬件集成

## 技术栈
- 前端：Vue 3 + Vite + ECharts + Web Speech API
- 后端：Python FastAPI + SQLite + WebSocket
- 硬件：Arduino Uno + 树莓派 4B，串口 JSON 通信
- 硬件模块：WS2812 LED、RC522 RFID、FSR402 压力传感器、BH1750 光强传感器
