# 摄像头参数同步任务

## 目标
将 `D:\Ai_project\smart_desktop\smartdesk_gesture_controller\hands` 中的摄像头参数设置与以下配置同步：

```python
CAMERA_INDEX = 0
EXPOSURE = -5
WIDTH = 640
HEIGHT = 480
# 强制使用 DirectShow
cap = cv2.VideoCapture(CAMERA_INDEX, cv2.CAP_DSHOW)
if not cap.isOpened():
    raise RuntimeError("Cannot open camera")
cap.set(cv2.CAP_PROP_FRAME_WIDTH, WIDTH)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, HEIGHT)
ret1 = cap.set(cv2.CAP_PROP_AUTO_EXPOSURE, 0)  # Windows DirectShow
ret2 = cap.set(cv2.CAP_PROP_EXPOSURE, EXPOSURE)
time.sleep(1)
actual_auto = cap.get(cv2.CAP_PROP_AUTO_EXPOSURE)
actual_exp = cap.get(cv2.CAP_PROP_EXPOSURE)
actual_fps_cfg = cap.get(cv2.CAP_PROP_FPS)
```

## 定位
代码中摄像头参数相关位置：

1. `gesture_config.py` 第 53-61 行：摄像头默认值配置。
2. `gesture_controller.py` 第 748-768 行：实际 `cv2.VideoCapture` 调用与曝光设置逻辑。

## 修改内容

### gesture_config.py
- `camera_auto_exposure: float = 0.25` → `camera_auto_exposure: float = 0`
- `camera_exposure: int = 50` → `camera_exposure: int = -5`

说明：Windows DirectShow 下 `CAP_PROP_AUTO_EXPOSURE` 的手动模式值为 `0`。

### gesture_controller.py `_open_camera()`
- `cap = cv2.VideoCapture(self.config.camera_index)` → `cap = cv2.VideoCapture(self.config.camera_index, cv2.CAP_DSHOW)`
- 在 `isOpened()` 校验通过后再设置分辨率。
- `cap.set(3, ...)` / `cap.set(4, ...)` → `cap.set(cv2.CAP_PROP_FRAME_WIDTH, ...)` / `cap.set(cv2.CAP_PROP_FRAME_HEIGHT, ...)`
- 设置曝光后增加 `time.sleep(1)`，让驱动生效。
- 读取回显变量重命名为 `actual_fps_cfg`，与目标代码保持一致。
