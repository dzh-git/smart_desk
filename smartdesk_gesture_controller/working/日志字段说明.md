# 手势控制日志字段说明

> 日志文件路径：`logs/gesture_record_YYYYMMDD_HHMMSS.jsonl`
> 每行是一条 JSON 记录，代表一帧的处理结果。

---

## 一、字段总览

| 字段名 | 类型 | 可能值 | 来源 |
|--------|------|--------|------|
| `timestamp` | float | Unix 时间戳（秒） | 系统时钟 |
| `mode` | string | `standby` / `presentation` / `presentation_pen` / `solidworks` / `paused` | GestureState |
| `mode_before_state_step` | string | 同上 | GestureState.step() 前 |
| `mode_after_state_step` | string | 同上 | GestureState.step() 后 |
| `state_result_mode` | string | 同上 | GestureState.step() 返回值 |
| `state_paused` | bool | `true` / `false` | GestureState.paused |
| `mode_changed` | bool | `true` / `false` | 本次帧是否发生模式切换 |
| `raw_gesture` | string/null | `ILoveYou` / `Closed_Fist` / `Open_Palm` / `Pointing_Up` / `Victory` / `None` | GestureRecognizer |
| `stable_gesture` | string/null | 同上 | GestureIntentTracker |
| `confidence` | float | 0.0 ~ 1.0 | GestureRecognizer |
| `hand_present` | bool | `true` / `false` | MediaPipe |
| `palm_x` | float/null | 0.0 ~ 1.0 / null | 关键点计算 |
| `palm_y` | float/null | 0.0 ~ 1.0 / null | 关键点计算 |
| `index_x` | float/null | 0.0 ~ 1.0 / null | 关键点 8 |
| `index_y` | float/null | 0.0 ~ 1.0 / null | 关键点 8 |
| `pinch_norm` | float/null | 0.0 ~ 1.0 / null | 关键点距离计算 |
| `intent_state` | string | 见下方详解 | GestureIntentTracker |
| `active_attempt` | string/null | 见下方详解 | GestureIntentTracker |
| `active_session` | string/null | 见下方详解 | GestureIntentTracker |
| `generated_intents` | list | 见下方详解 | GestureState.step() |
| `generated_events` | list | 见下方详解 | GestureIntentTracker |

## 二、各字段详细说明

### 1. `timestamp`
- **含义**：当前帧的处理时间戳（Unix 时间，单位：秒，保留毫秒）
- **用途**：计算两帧之间的时间差，判断超时、持续时间等
- **示例**：`536405.031`

---

### 2. `mode`
- **含义**：当前状态机所处的模式（即程序"认为"自己当前在哪个模式）
- **可能值**：

| 值 | 含义 |
|----|------|
| `"standby"` | 待机模式，不控制鼠标键盘，只识别手势做模式切换 |
| `"presentation"` | PPT 演示模式，Open_Palm 挥手翻页，Victory 进入画笔 |
| `"presentation_pen"` | PPT 画笔子模式，Pointing_Up 移动画笔，PINCH 画线 |
| `"solidworks"` | SolidWorks 模式，Open_Palm 旋转，Victory 平移，PINCH 缩放 |
| `"paused"` | 暂停模式，所有手势不触发动作，等待恢复 |

- **注意**：这是日志**记录时刻**的模式，可能在 `step()` 处理前或后，取决于日志代码的插入位置。

---

### 3. `mode_before_state_step`
- **含义**：进入 `GestureState.step()` **之前**的模式（即上一帧结束时的模式）
- **用途**：判断 `step()` 调用前后模式是否发生变化
- **示例**：`"standby"`

---

### 4. `mode_after_state_step`
- **含义**：`GestureState.step()` **返回后**、但**尚未更新 `self.mode`** 时的中间结果模式
- **用途**：调试 `step()` 内部逻辑是否正确计算了目标模式
- **注意**：正常情况下应与 `state_result_mode` 相同

---

### 5. `state_result_mode`
- **含义**：`GestureState.step()` 的**返回值**中的模式（即 `step()` "建议"切换到的模式）
- **与 `mode` 的区别**：
  - `mode` 是**实际生效**的模式（已写入 `self.mode`）
  - `state_result_mode` 是 `step()` **返回的建议模式**，正常情况下两者应一致
  - 如果不一致，说明 `step()` 返回后没有被正确消费

---

### 6. `state_paused`
- **含义**：程序是否处于暂停状态
- **可能值**：

| 值 | 含义 |
|----|------|
| `true` | 暂停中，所有手势不触发动作 |
| `false` | 正常运行，手势控制已激活 |

- **如何切换**：按 `Ctrl+Alt+G`（或调试窗口按 `p` / `Space`）

---

### 7. `mode_changed`
- **含义**：当前帧是否发生了模式切换
- **可能值**：

| 值 | 含义 |
|----|------|
| `true` | 模式发生了切换（如 `standby` → `presentation`） |
| `false` | 模式未变化 |

- **计算方式**：`mode_after_state_step != mode_before_state_step`

---

### 8. `raw_gesture`
- **含义**：识别层（GestureRecognizer 或规则兜底）对**当前帧**的手势分类结果（即时输出，未稳定）
- **可能值**：

| 值 | 含义 |
|----|------|
| `"ILoveYou"` | I Love You 手势（拇指+食指+小指伸出） |
| `"Closed_Fist"` | 握拳 |
| `"Open_Palm"` | 张开手掌 |
| `"Pointing_Up"` | 单指向上（食指伸出） |
| `"Victory"` | V 字手势（食指+中指伸出） |
| `null` / `"None"` | 未识别到有效手势 |

- **特点**：每一帧独立输出，可能抖动（如这一帧是 `ILoveYou`，下一帧变成 `null`）
- **与 `stable_gesture` 的区别**：`raw_gesture` 是即时结果，`stable_gesture` 是经过多帧稳定确认后的结果

---

### 9. `stable_gesture`
- **含义**：经过 `GestureIntentTracker` 多帧稳定确认后的手势（去抖动后的结果）
- **稳定条件**：
  1. 同一手势在最近 `gesture_enter_window_frames`（默认 10）帧中出现 ≥ `gesture_enter_frames`（默认 4）帧
  2. 对于 GestureRecognizer 结果，还需 `confidence >= gesture_enter_confidence`（默认 0.65）
- **可能值**：同 `raw_gesture`，但更稳定
- **用途**：用于触发需要"保持"的手势动作（如模式切换、画笔切换）

---

### 10. `confidence`
- **含义**：GestureRecognizer 对当前帧手势分类的置信度
- **范围**：0.0 ~ 1.0
- **阈值**：`min_gesture_confidence`（默认 0.65）
  - 如果 `confidence < 0.65`，回退到规则识别
  - 如果规则识别也不成功，输出 `None`
- **注意**：规则识别没有置信度输出（此时 `confidence` 可能为 0.0 或上一个识别器结果的值）

---

### 11. `hand_present`
- **含义**：MediaPipe 是否在当前帧检测到手
- **可能值**：

| 值 | 含义 |
|----|------|
| `true` | 检测到手（即使 `raw_gesture=null`，也表示有手但分类失败） |
| `false` | 未检测到手（真正的"手丢失"） |

- **关键区别**：
  - `hand_present=true, raw_gesture=null`：有手但分类暂时失败，**不启动手丢失计时器**
  - `hand_present=false`：**启动手丢失计时器**，超过 `hand_lost_timeout`（默认 1.0 秒）后触发 `release_all`

---

### 12. `palm_x` / `palm_y`
- **含义**：手掌中心的归一化坐标（用于计算滑动位移）
- **单位**：归一化坐标（0.0 ~ 1.0）
  - `(0.0, 0.0)` = 图像左上角
  - `(1.0, 1.0)` = 图像右下角
- **计算方式**：MediaPipe 关键点 0（手腕中心）和关键点 9（中指掌指关节）的中点
  ```python
  palm_x = (wrist.x + middle_mcp.x) / 2.0
  palm_y = (wrist.y + middle_mcp.y) / 2.0
  ```
- **用途**：
  - ILoveYou 滑动模式切换（计算 `dx = palm_x - start_palm_x`）
  - Open_Palm 挥手翻页（PPT）
- **无值时**：`null`（未检测到手，或 landmarks 无效）

---

### 13. `index_x` / `index_y`
- **含义**：食指指尖（MediaPipe 关键点 8）的归一化坐标
- **单位**：归一化坐标（0.0 ~ 1.0）
- **用途**：
  - `presentation_pen` 模式中，Pointing_Up 移动时以 `index_tip_xy` 作为指针位置，控制鼠标移动
  - 比 `palm_xy` 更精确，适合画笔等精细控制
- **无值时**：`null`（未检测到手，或 landmarks 无效）

---

### 14. `pinch_norm`
- **含义**：拇指指尖（关键点 4）与食指指尖（关键点 8）之间的**归一化距离**（尺度不变）
- **单位**：归一化距离（0.0 ~ 1.0，除以手的大小 `hand_size`）
- **阈值**：

| 阈值参数 | 默认值 | 含义 |
|-----------|---------|------|
| `pinch_threshold` | 0.045 | 小于此值 = 捏合状态（触发 PINCH 开始） |
| `pinch_release_threshold` | 0.065 | 大于此值 = 释放状态（触发 PINCH 释放） |
| 两者之间 | - | 滞回区间（边界抖动区，状态保持上一帧） |

- **与 `pinch_distance` 的区别**：
  - `pinch_distance` 是原始像素距离或归一化绝对距离，会随手离摄像头远近变化
  - `pinch_distance_norm` 是除以 `hand_size` 后的归一化距离，**尺度不变**，更适合作为阈值判断
- **无值时**：`null`（未检测到手，或无法计算距离）

---

### 15. `intent_state`
- **含义**：`GestureIntentTracker` 的内部状态机状态（表示"当前在做什么"）
- **可能值**：

| 值 | 含义 | 触发条件 |
|----|------|----------|
| `"idle"` | 空闲，没有活跃尝试或会话 | 初始状态，或尝试/会话结束后 |
| `"hand_lost"` | 手丢失中 | `hand_present=false` 且未超时 |
| `"attempt:mode_swipe:armed"` | 模式切换尝试已武装，等待轨迹 | `stable_gesture=ILoveYou` 且保持 ≥ `mode_arm_duration` |
| `"attempt:mode_swipe:tracking"` | 模式切换尝试正在跟踪轨迹 | 已进入 armed 且 `palm_xy` 有效 |
| `"attempt:mode_swipe:committed"` | 模式切换尝试已提交（位移达标） | `dx` 超过 `iloveyou_swipe_threshold_x` |
| `"attempt:page_swipe:armed"` | 翻页尝试已武装 | `stable_gesture=Open_Palm` 且保持 ≥ `page_arm_duration` |
| `"attempt:page_swipe:tracking"` | 翻页尝试正在跟踪轨迹 | 已进入 armed 且 `palm_xy` 有效 |
| `"attempt:page_swipe:committed"` | 翻页尝试已提交 | `dx` 超过 `swipe_threshold_x` |
| `"attempt:fist_hold:armed"` | 握拳保持尝试已武装 | `stable_gesture=Closed_Fist` 且保持 ≥ `fist_hold_arm_duration` |
| `"attempt:fist_hold:tracking"` | 握拳保持尝试正在计时 | 已进入 armed 且持续时间在统计 |
| `"attempt:fist_hold:committed"` | 握拳保持尝试已提交 | 保持时间 ≥ `fist_hold_duration` |
| `"session:rotate:active"` | 旋转会话活跃中 | Open_Palm 稳定后开始旋转（SolidWorks） |
| `"session:pan:active"` | 平移会话活跃中 | Victory 稳定后开始平移（SolidWorks） |
| `"session:pen_draw:active"` | 画笔绘制会话活跃中 | PINCH 开始后画线（PPT 画笔） |

- **用途**：判断 Tracker 在哪个阶段，方便调试为什么没有触发动作

---

### 16. `active_attempt`
- **含义**：当前活跃的短期尝试（Attempt）的描述字符串
- **格式**：`"intent_type:phase:attempt_id"`
  - `intent_type`：`mode_swipe` / `page_swipe` / `fist_hold`
  - `phase`：`armed` / `tracking` / `committed`
  - `attempt_id`：唯一标识（如 `att_1`）
- **可能值**：

| 值 | 含义 |
|----|------|
| `null` | 当前没有活跃的尝试 |
| `"mode_swipe:armed:att_1"` | 模式切换尝试已武装，等待轨迹 |
| `"mode_swipe:tracking:att_1"` | 模式切换尝试正在跟踪轨迹 |
| `"mode_swipe:committed:att_1"` | 模式切换尝试已提交 |

- **用途**：确认当前是否有活跃的尝试，避免重复提交

---

### 17. `active_session`
- **含义**：当前活跃的连续控制会话（Session）的描述字符串
- **格式**：`"control_type:phase:session_id"`
  - `control_type`：`rotate` / `pan` / `pen_draw`
  - `phase`：`active` / `ending`
  - `session_id`：唯一标识（如 `sess_1`）
- **可能值**：

| 值 | 含义 |
|----|------|
| `null` | 当前没有活跃的会话 |
| `"rotate:active:sess_1"` | 旋转会话活跃中（SolidWorks） |
| `"pan:active:sess_1"` | 平移会话活跃中（SolidWorks） |
| `"pen_draw:active:sess_1"` | 画笔绘制会话活跃中（PPT 画笔） |

- **关键约束**：同一时间只能有一个 active session，旋转和平移不能同时进行（互斥）

---

### 18. `generated_intents`
- **含义**：`GestureState.step()` 生成的 `ActionIntent` 列表（即"要执行什么动作"）
- **每个元素的字段**：

| 字段 | 类型 | 含义 |
|------|------|------|
| `type` | string | 动作类型（见下表） |
| `key` | string/null | 按键名称（如 `"esc"`、`"f5"`） |
| `button` | string/null | 鼠标按钮（如 `"left"`、`"middle"`） |
| `value` | float/null | 数值参数（如缩放步长） |

- **`type` 可能值**：

| 值 | 含义 | 示例 |
|----|------|------|
| `"press"` | 按下并释放键盘按键 | `{"type":"press","key":"esc"}` |
| `"key_down"` | 按下键盘按键（不释放） | `{"type":"key_down","key":"shift"}` |
| `"key_up"` | 释放键盘按键 | `{"type":"key_up","key":"shift"}` |
| `"mouse_down"` | 按下鼠标按钮（不释放） | `{"type":"mouse_down","button":"middle"}` |
| `"mouse_up"` | 释放鼠标按钮 | `{"type":"mouse_up","button":"middle"}` |
| `"mouse_move"` | 移动鼠标 | `{"type":"mouse_move","dx":10,"dy":-5}` |
| `"scroll"` | 滚轮滚动 | `{"type":"scroll","dy":3}` |
| `"release_all"` | 释放所有按住的按键/鼠标按钮 | `{"type":"release_all"}` |

- **无动作时**：`[]`（空列表）

---

### 19. `generated_events`
- **含义**：`GestureIntentTracker.step()` 生成的 `ControlEvent` 列表（即"检测到了什么意图"）
- **每个元素的字段**：

| 字段 | 类型 | 含义 |
|------|------|------|
| `type` | string | 事件类型（见下表） |
| `attempt_id` | string/null | 关联的尝试 ID |
| `dx` | float | x 方向位移（归一化） |
| `dy` | float | y 方向位移（归一化） |
| `phase` | string | 事件阶段（`""` / `"begin"` / `"update"` / `"end"`） |
| `reason` | string | 触发原因（`""` / `"committed"` / `"hand_lost_timeout"` / `"cancelled"` / `"released"`） |
| `position` | list/null | 触发时的手掌坐标 `[palm_x, palm_y]` |

- **`type` 可能值**：

| 值 | 含义 |
|----|------|
| `"mode_swipe_right"` | ILoveYou 右滑，切换到 presentation 或 standby |
| `"mode_swipe_left"` | ILoveYou 左滑，切换到 solidworks 或 standby |
| `"page_swipe_right"` | Open_Palm 向右挥，PPT 下一页 |
| `"page_swipe_left"` | Open_Palm 向左挥，PPT 上一页 |
| `"fist_hold_committed"` | Closed_Fist 保持超时，提交退出/释放 |
| `"rotate_begin"` | Open_Palm 稳定后开始旋转（SolidWorks） |
| `"rotate_update"` | 旋转持续更新（SolidWorks） |
| `"rotate_end"` | 旋转结束（手离开或手势变化） |
| `"pan_begin"` | Victory 稳定后开始平移（SolidWorks） |
| `"pan_update"` | 平移持续更新（SolidWorks） |
| `"pan_end"` | 平移结束 |
| `"zoom_update"` | PINCH 距离变化，触发缩放（SolidWorks） |
| `"pen_mode_toggle"` | Victory 保持，切换画笔模式（PPT） |
| `"pen_draw_begin"` | PINCH 开始，开始画线（PPT 画笔） |
| `"pen_draw_update"` | 画线持续更新 |
| `"pen_draw_end"` | 画线结束（PINCH 释放） |
| `"cancel"` | 尝试或会话被取消（手丢失、方向不一致等） |
| `"hand_lost_timeout"` | 手丢失超时，触发安全释放 |

- **无事件时**：`[]`（空列表）

## 三、典型调试场景

### 场景 1：ILoveYou 滑动没有切换模式

**检查顺序**：

1. `state_paused` 是否为 `false`？→ 如果为 `true`，按 `Ctrl+Alt+G` 恢复
2. `stable_gesture` 是否为 `"ILoveYou"`？→ 确认手势被稳定识别
3. `intent_state` 是否变为 `"attempt:mode_swipe:armed"`？→ 确认进入 armed 阶段
4. `intent_state` 是否变为 `"attempt:mode_swipe:tracking"`？→ 确认开始跟踪轨迹
5. `palm_x` 变化是否超过 `iloveyou_swipe_threshold_x`（默认 0.22）？→ 确认滑动幅度足够
6. `generated_events` 是否包含 `mode_swipe_right` 或 `mode_swipe_left`？→ 确认事件已生成
7. `mode_changed` 是否为 `true`？→ 确认模式已切换

---

### 场景 2：PPT 翻页不灵敏（一次挥手翻多页）

**检查**：

1. `generated_events` 中 `page_swipe_right` 或 `page_swipe_left` 是否连续出现？→ 如果连续出现，调大 `page_turn_cooldown`
2. `palm_x` 变化是否远超过 `swipe_threshold_x`？→ 如果远超，调大阈值或减少挥手幅度

---

### 场景 3：程序崩溃或鼠标卡住

**检查**：

1. `generated_intents` 中是否有 `release_all`？→ 如果没有，说明释放逻辑有问题
2. 最后一帧的 `active_session` 是否为 `null`？→ 如果非 null，说明会话没有正确清理
3. 日志是否在 `generated_intents` 包含 `press("esc")` 后突然结束？→ 可能是 `pyautogui` 崩溃

---

## 四、字段关系图

```
摄像头帧
    ↓
GestureRecognizer / 规则兜底
    ↓
raw_gesture, confidence, hand_present
    ↓
GestureIntentTracker（稳定确认 + 轨迹跟踪）
    ↓
stable_gesture, intent_state, active_attempt, generated_events
    ↓
GestureState.step()（状态机处理事件）
    ↓
mode, mode_changed, generated_intents
    ↓
ActionLayer（执行 pyautogui 动作）
```

## 五、附录：归一化坐标示意图

```
图像坐标系统（归一化）

(0.0, 0.0) ──────────────────── (1.0, 0.0)
    │                                  │
    │                                  │
    │        手掌中心                    │
    │        (palm_x, palm_y)          │
    │        e.g. (0.53, 0.60)       │
    │                                  │
    │                                  │
(0.0, 1.0) ──────────────────── (1.0, 1.0)

- x 轴：从左到右，0.0 → 1.0
- y 轴：从上到下，0.0 → 1.0
- 滑动方向：palm_x 增大 = 向右滑，palm_x 减小 = 向左滑
```
