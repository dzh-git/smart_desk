手势控制日志字段说明
每行一条 JSON，代表一帧的处理结果。

## 基本字段

timestamp       当前帧时间戳（Unix 秒）
mode            当前模式：standby / presentation / presentation_pen / solidworks / paused
state_paused    是否暂停（true/false）
mode_changed    当前帧是否发生模式切换（true/false）

## 手势识别

raw_gesture     当前帧即时手势（未稳定）：ILoveYou / Closed_Fist / Open_Palm / Pointing_Up / Victory / None
stable_gesture  多帧稳定后的手势（去抖动）
confidence      GestureRecognizer 置信度（0.0~1.0）

## 手部状态

hand_present    是否检测到手（true/false）
palm_x, palm_y 手掌中心归一化坐标（0.0~1.0），用于计算滑动
index_x, index_y 食指指尖归一化坐标，画笔模式用
pinch_norm     拇指-食指归一化距离（0.0~1.0），用于 PINCH 判断

## 意图跟踪器状态

intent_state    GestureIntentTracker 内部状态机状态
               常见值：idle / hand_lost / attempt:XXX:armed / attempt:XXX:tracking
               / attempt:XXX:committed / session:XXX:active
active_attempt 当前活跃的短期尝试（如 mode_swipe:armed:att_1），null 表示无
active_session 当前活跃的连续控制会话（如 rotate:active:sess_1），null 表示无

## 输出

generated_intents  GestureState.step() 生成的动作列表（要执行什么）
                  常见类型：press / key_down / key_up / mouse_down / mouse_up
                  / mouse_move / scroll / release_all
generated_events   GestureIntentTracker 生成的事件列表（检测到了什么意图）
                  常见类型：mode_swipe_right/left / page_swipe_right/left
                  / rotate_begin/update/end / pan_begin/update/end
                  / zoom_update / pen_draw_begin/update/end / cancel
                  / hand_lost_timeout

## 快速调试

手势不触发？检查顺序：
1. state_paused 是否为 false
2. stable_gesture 是否正确识别
3. intent_state 是否正常推进（armed → tracking → committed）
4. generated_events 是否有对应事件
5. mode_changed / generated_intents 是否有输出
