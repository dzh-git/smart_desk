# 项目目标与预期结果

## 项目定位

**SmartDesk** — 智能会议桌系统。实体会议桌集成 10 座位硬件（TOF 传感器 + LED 灯带 + 触控平板），由中央 NUC 驱动，提供签到、发言识别、实时翻译、投票、服务呼叫一体化体验。

## 核心目标

| 目标 | 描述 |
|------|------|
| **无感签到** | 入座自动检测（TOF），平板弹窗确认，无需 RFID/扫码 |
| **发言管理** | 管理员指定发言席，全桌平板同步显示发言人翻译 |
| **实时双语** | 中文发言 → 英文翻译；英文发言 → 中文翻译。<2 秒端到端延迟 |
| **会议投票** | 管理员发起投票，实时环形图结果，支持匿名/记名 |
| **服务呼叫** | 座位一键呼叫咖啡/茶/水/其他，管理员端即时通知 |
| **议程管理** | 会议议程增删，全桌同步 |
| **10 座联动** | 所有座位平板通过 WebSocket 实时同步状态 |

## 预期效果（用户视角）

### 会前
1. 参会者入座 → TOF 检测 → 座位 LED 亮起 → 平板弹出签到确认
2. 签到后显示姓名、职位。未签到座位显示空位状态
3. 管理员创建会议、添加议程、添加参会者

### 会中
1. 管理员指定发言席 → 该座位平板显示录音按钮
2. 发言人点击麦克风说话 → 1-2 秒后屏幕显示 interim 中文文本（带闪烁光标）
3. 说完一句（VAD 自动断句） → final 结果上屏为 line1（半透明），新句继续在 line2 刷新
4. 英文翻译同步显示在每行中文下方
5. 所有参会者平板通过 WebSocket 实时看到翻译结果
6. 管理员发起投票 → 各平板弹出投票选项 → 实时环形图统计
7. 任意座位可呼叫服务 → 管理员端即时通知

### 会后
1. 管理员结束会议 → 所有平板恢复待机状态
2. 翻译历史可回溯查看（200 条/会议，FIFO）
3. 投票结果、服务呼叫记录可查

## 成功标准

| 指标 | 目标值 |
|------|--------|
| STT 端到端延迟（final） | ≤ 3 秒 |
| interim 刷新延迟 | ≤ 2 秒 |
| 翻译准确率 | 可理解（非专业翻译场景） |
| 并发处理能力 | 4 路 STT 同时处理 |
| WebSocket 广播延迟 | < 100ms |
| 座位检测响应 | < 1 秒 |
| 系统稳定性 | 连续运行 2 小时无崩溃 |

## 非目标（明确不做）

- 不提供离线语音识别（需要 NUC 后端）
- 不支持 10 人以上同时发言识别
- 不做专业级翻译质量（仅会议沟通辅助）
- 不做语音合成/TTS
- 不做会议录制与回放（仅保留文本历史）
