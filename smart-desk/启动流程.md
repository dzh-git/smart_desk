# SmartDesk 调试启动流程

> 适用于 PC 切换网络后 IP 变化的情况

---

## 1. 获取本机 IP

```bash
# Windows PowerShell / CMD
ipconfig | findstr "IPv4"
```

记下当前 IP，假设为 `<PC_IP>`。

---

## 2. 启动后端

```bash
cd smart-desk/backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

验证：浏览器打开 `http://127.0.0.1:8000/docs`，应显示 FastAPI 文档页。

### 可能存在端口号被占用的情况：
端口 8000 被占用 — 上次启动的后端进程还在跑。

for /f "tokens=5" %a in ('netstat -ano ^| findstr :8000 ^| findstr LISTENING') do taskkill /PID %a /F

杀掉后再重新 uvicorn main:app --reload --host 0.0.0.0 --port 8000 即可。
---

## 3. 启动前端

```bash
cd smart-desk/frontend
npx vite --host 0.0.0.0 --port 5173
```

验证：浏览器打开 `http://127.0.0.1:5173`，应显示会议列表页。

---

## 4. 防火墙（仅首次/重置后需要）

如果平板无法访问，以管理员身份运行 PowerShell：

```powershell
netsh advfirewall firewall add rule name="SmartDesk-5173" dir=in action=allow protocol=TCP localport=5173
netsh advfirewall firewall add rule name="SmartDesk-8000" dir=in action=allow protocol=TCP localport=8000
```

---

## 5. 平板访问

平板与 PC 连同一 WiFi，浏览器打开：

```
http://<PC_IP>:5173
```

---

## 6. 调试检查项

| 检查点 | 正常表现 |
|--------|---------|
| 会议列表 | 显示"季度产品评审会" |
| 进入会议 | 5 个 Tab 正常切换 |
| WS 指示灯 | 左下显示 `● 实时连接`（绿色） |
| 参会者面板 | 8 人列表（张伟~周婷） |
| 服务呼叫 | 点"咖啡"，记录中 seat_id 与 URL 参数一致 |
| 投票 | 各座投不同选项，环形图实时更新 |
| 翻译 | 语音/文字输入后显示翻译结果 |

---

## 7. 停止服务

```
Ctrl+C 停止前端 (5173)
Ctrl+C 停止后端 (8000)
```
