# 2026-06-04 工作日志

## uvicorn 环境修复

**问题**：`start.bat` 中使用裸 `uvicorn` 命令，在 Git Bash/VSCode 终端中因 `C:\Users\刁智怀\` 中文路径编码问题导致 `ModuleNotFoundError`。

**解决**：
1. 在项目目录创建虚拟环境：`D:\Ai_project\smart_desktop\smart-desk\.venv\`，基于 Anaconda Python 3.12.4
2. 用清华镜像 pip install 全部 backend 依赖（torch 2.2.0、transformers、funasr 等 80+ 包）
3. 修改 `start.bat`：`uvicorn` → `.venv\Scripts\python.exe -m uvicorn`
4. 修改 `start.sh`：`uvicorn` → `.venv/bin/python -m uvicorn`
5. `.gitignore` 添加 `.venv/`

**效果**：虚拟环境路径不含中文，Git Bash 和 CMD 均可正常启动。
