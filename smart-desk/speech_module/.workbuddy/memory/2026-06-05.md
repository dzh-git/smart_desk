## 语音识别模块技术摘要分析

- 完整分析了 `speech_module/` 下全部 10 个源文件 + 2 个测试文件
- 输出了面向 SmartDesk 集成规划的 `speech_module_tech_summary.md` (24KB, 7 章节)
- 关键发现：
  - 架构：后端 Python 函数调用模式，非 HTTP/WebSocket。FunASR Paraformer Streaming + Paraformer-large 2pass
  - 依赖：FunASR/PyTorch/transformers/scipy/numpy/soundfile，可在纯 CPU 运行，~1.75GB 模型
  - 输入：float32 16kHz 单声道 numpy 数组，自动重采样和转单声道
  - 输出：纯文本 string，无 confidence/timestamp/speaker 字段
  - 第一版建议：HTTP multipart 上传 → transcribe() → 返回文本，暂缓 WebSocket 流式/翻译/说话人识别
  - 缺失：无 Speaker Diarization、无降噪 DSP、无 confidence 分数、无时间戳对齐、STT 测试覆盖不足
- 文档路径：`.workbuddy/speech_module_tech_summary.md`
