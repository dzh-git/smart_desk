## 启动方式

```bash
# 一键启动
start.bat

# 或分别启动：

# 后端
cd smart-desk
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

# 前端
cd smart-desk/frontend
npx vite --host 0.0.0.0 --port 5173
```

- 前端: http://localhost:5173
- 平板访问: http://<NUC_IP>:5173?seat=1 (1-8)
- 管理员（无 ?seat 参数）: http://<NUC_IP>:5173
- 后端 API 文档: http://localhost:8000/docs
- 调试状态: http://localhost:8000/api/debug/state
