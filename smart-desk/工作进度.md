## 启动方式

```bash
# 后端
cd smart-desk/backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 前端
cd smart-desk/frontend
npm run dev
```

- 前端: http://localhost:5173
- 后端 API 文档: http://localhost:8000/docs
