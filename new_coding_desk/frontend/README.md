# SmartDesk Frontend

React/Vite 前端位于 `src/`，提供主持人端、9 个席位端与中央大屏。席位端规范为 `/seat/:seatId`，有效范围为 `1..9`，其中 `seat 1` 是主持人位。

前端状态、交互和视觉规则分别见：

- `../docs/FRONTEND_STATE_SPEC.md`
- `../docs/FRONTEND_INTERACTION_SPEC.md`
- `../docs/FRONTEND_VISUAL_SPEC.md`
