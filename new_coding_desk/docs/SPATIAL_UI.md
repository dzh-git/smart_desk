# SmartDesk 空间界面

## 场景与会议状态

| 界面 | 三维主体 | 业务信号 |
| --- | --- | --- |
| `/admin`、已解锁的 `/host` 总览 | 紫铜九席轨道与多面核心 | 人员分配、签到、发言席、选中席位和会议状态 |
| 议程、投票 | 琥珀色分段光环 | 当前议题、投票开关与票数 |
| 服务、记录 | 翡翠色空间网络 | 待处理服务数量和已处理反馈 |
| `/seat/2` 至 `/seat/9` | 靛紫席位晶体 | 本席签到、发言、投票与连接状态 |
| `/display` | 银紫双环会议核心 | 会议状态、当前议程和投票进度 |
| `/screen` 等待、重连或故障 | 青白透镜 | 共享流连接状态。连接成功时由 WebRTC 播放画面接管主体区域。 |
| 席位与主持人设备验证 | 粉紫感应环 | 设备桥接与签到可用状态 |

鼠标与触控可拖动场景，聚焦视窗后可按方向键旋转。主持人总览中的九个三维席位可点选，二维席位控件提供同一操作入口。工作区切换时，镜头推进、改变视场角并滚转。粒子沿涡流聚散，原场景先收拢再重组成新形态。连续切换可打断转场，控件与业务状态即时切换。实际签到、议程、投票、服务及发言变化触发短脉冲或衰减。重复的轮询快照不会反复播放动效。

## 界面焦点

主持端的三维场景在会场侧边显示。在议程、投票、人员、服务和记录工作区，场景缩入标题旁，给操作内容留出空间。参会端仅在会场呈现场景，字幕、投票和服务各有独立视图。大屏将当前议题或当前投票作为主内容。

场景中的画质与减少动效设置仍可打开。实时帧率和渲染引擎标识已从普通界面移除。

## 渲染与画质

- React 页面将现有的业务状态投射为 `SpatialState`。`SpatialProvider` 在应用内导航时迁移同一 Canvas，延迟加载 Three.js，并在视窗离开可视范围或标签页隐藏时暂停绘制。
- `world.ts` 生成不同拓扑的模型、PBR 金属与带菲涅耳边缘光的晶体。支持浮点渲染目标时使用程序化环境经 PMREM 提供反射与环境光。雾、晶体边缘、投影与能量光束为实时视觉近似。
- `particles.ts` 在 CPU 的预分配缓冲区中积分粒子速度与位置，计算寿命、目标形态、涡流、指针作用力和湍流。GPU 以批处理绘制粒子、空间尘与速度拖尾。高、中、低档分别模拟最多 1,728、768、288 个活动粒子。
- `director.ts` 编排镜头、截断和衔接连续操作。`lens.ts` 对实时场景的纹理做 GLSL 辉光、电影曲线色调映射和转场色散。引力透镜和径向拖影是屏幕空间近似。
- 场景右上角可在自动、高、中、低四档间切换并启用减少动效。自动档根据连续帧率采样调整绘制像素、粒子和后处理。低档保留几何主体并关闭辉光与拖尾。减少动效跟随浏览器系统设置。轮询重复返回相同状态时，视窗保持静止，业务状态变化或主动旋转视角时重绘。
- WebGL 2 初始化失败或上下文丢失时，界面在相同位置切换为二维视窗。业务控件、文本状态和设备错误提示仍可操作。浏览器恢复上下文后重建图形资源。

## 启动和验证

从现有 [演示运行手册](DEMO_RUNBOOK.md) 启动后端和前端，访问 `/admin`。有独立测试库时可用 `ENABLE_DEMO_SEED=true` 预置活跃会议，前端以 `npm run demo` 启用设备预览。生产构建仍使用 `npm run build`。画质和动效选项同样适用于生产界面。

在 `new_coding_desk/frontend` 执行：

```bash
npm run typecheck
npm run lint
npm test -- --run
npm run build
```

用已启动的演示前端和含活跃样例会议的测试库运行浏览器验证。`SMARTDESK_PRESENTATION_BASE_URL` 指向该前端。无硬件 GPU 的 Chromium 可使用 `SMARTDESK_PLAYWRIGHT_WEBGL=software`。

```bash
SMARTDESK_SPATIAL_E2E=true SMARTDESK_PRESENTATION_BASE_URL=http://127.0.0.1:5173 \
  npx playwright test e2e/spatial-rendering.spec.ts
```

验证包括真实 WebGL 上下文、工作区切换、画质偏好、键盘运镜、路由间复用 Canvas、上下文丢失与恢复，以及初始化失败后的二维席位操作。会议操作一轮回归沿用运行手册中的 `presentation-flow.spec.ts`，该测试使用独立的空白测试数据库。浏览器和 WebView 启用 WebGL 2 的实际吞吐量、Windows 原生共享、Office 与 SolidWorks 控制、人脸摄像头及 ESP32 仍需现场设备验收。 [聚焦界面截图](../../docs/integration/focused-presentation/README.md)
