# Phase 03: 前端契约基础

## 阶段目标

建立可复用的前端领域类型、环境配置和 HTTP 客户端，不改变主要页面行为。

## 前置条件与允许读取

- Phase 02 已通过验证。
- 可读取本阶段文档、`docs/API_SPEC.md` 和当前 `frontend/`。

## 允许修改范围

- `frontend/` 中的类型、配置、API 客户端、测试和 mock 数据模块
- 不修改后端

## 修改内容

- 建立会议、议程、参会者、座位、投票、服务呼叫和翻译记录类型。
- 添加 `VITE_API_BASE_URL` 等环境配置。
- 实现统一 HTTP 客户端、错误归一化和资源查询基础。
- 明确 mock 数据只用于展示或开发回退，不与真实响应类型混杂。

## 验证与验收

```powershell
cd frontend
npm run build
npm test -- --run
```

- 类型检查和构建必须成功。
- API 客户端测试覆盖成功响应、错误响应和网络失败。

## 停止条件

页面回归、构建失败或客户端错误格式未统一时，不进入 Phase 04。
