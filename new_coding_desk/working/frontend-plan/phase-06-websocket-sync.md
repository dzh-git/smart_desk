# Phase 06: WebSocket 同步

## 阶段目标

接入服务端事件通知，使管理端在资源变化后重新获取真实数据。

## 前置条件与允许读取

- Phase 05 已通过验证。
- 可读取本阶段文档、`docs/WEBSOCKET_PROTOCOL.md`、`docs/API_SPEC.md` 和相关前端同步模块。

## 允许修改范围

- `frontend/` 中的 WebSocket、资源刷新和连接状态模块及测试
- 不修改后端

## 修改内容

- 建立 WebSocket 连接、断线状态和重连处理。
- 收到事件后通过 HTTP 重新获取对应资源。
- 不在前端根据事件负载推导复杂业务状态，不发送客户端 ping。

## 验证与验收

执行前端构建和 WebSocket 单元测试。启动前后端后，浏览器验证座位与会议状态变化会自动刷新，断开连接状态可见。

## 停止条件

事件导致前端状态漂移、重连失效或构建失败时，不进入 Phase 07。
