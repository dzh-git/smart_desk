# Phase 05: 管理端数据接入

## 阶段目标

将管理端会议概览、议程和座位展示接入真实 HTTP API。

## 前置条件与允许读取

- Phase 04 已通过验证。
- 可读取本阶段文档、`docs/API_SPEC.md` 和相关前端管理端模块。

## 允许修改范围

- `frontend/` 中的管理端页面、会议与座位查询模块及测试
- 不修改后端

## 修改内容

- 默认路径展示管理端。
- 接入活动会议、议程、参会者和座位数据。
- 会议桌始终展示 10 个座位，不因参会者缺失而隐藏空座位。
- 提供加载、空数据和错误状态，不调用 `/api/dashboard`。

## 验证与验收

```powershell
cd frontend
npm run build
npm test -- --run
```

启动前后端后，用浏览器检查无活动会议、有活动会议和部分空座位状态。

## 停止条件

管理端依赖 mock 数据、隐藏空座位或构建失败时，不进入 Phase 06。
