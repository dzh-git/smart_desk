# Phase 10: 翻译占位

## 阶段目标

将字幕面板接入翻译记录接口，同时保持语音识别为占位能力。

## 前置条件与允许读取

- Phase 09 已通过验证。
- 可读取本阶段文档、`docs/API_SPEC.md` 和前后端翻译相关模块。

## 允许修改范围

- 前端翻译与字幕模块及测试
- 必要的后端翻译接口修复及测试

## 修改内容

- 接入翻译记录查询与文本占位提交接口。
- 展示双语字幕时间线、空状态和错误状态。
- 保留 “Speech interface reserved” 区域。
- 不实现麦克风、VAD、ASR 或音频上传。

## 验证与验收

先运行后端翻译定向测试，再运行完整 `pytest -q`；执行前端构建和翻译测试；浏览器验证空状态与记录展示。

## 停止条件

出现音频采集实现、翻译记录无法展示或任一测试失败时，不进入 Phase 11。
