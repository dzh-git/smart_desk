# Phase 07: 座位平板与签到

## 阶段目标

实现座位平板模式、参会者签到和可选的开发演示座位控制。

## 前置条件与允许读取

- Phase 06 已通过验证。
- 可读取本阶段文档、`docs/API_SPEC.md` 和相关座位端前端模块。

## 允许修改范围

- `frontend/` 中的座位端页面、签到、开发控制和测试
- 不修改后端

## 修改内容

- `?seat=1..10` 进入对应座位平板端，非法参数显示明确错误。
- 展示座位状态、当前参会者、会议和当前发言人。
- 接入参会者选择与签到。
- 使用 `VITE_ENABLE_DEMO_CONTROLS=true` 控制开发占用与离座按钮。

## 验证与验收

执行前端构建和签到相关测试。浏览器验证合法座位、非法座位、未占用、已占用和签到完成状态。

## 停止条件

非法座位参数可进入正常页面、签到状态不刷新或构建失败时，不进入 Phase 08。
