# Phase 11: 启动与最终验证

## 阶段目标

提供一键启动方式，并完成完整演示流程验证。

## 前置条件与允许读取

- Phase 10 已通过验证。
- 可读取本阶段文档、根目录启动脚本、`docs/API_SPEC.md`、`docs/WEBSOCKET_PROTOCOL.md` 和已实现模块。

## 允许修改范围

- 根目录启动脚本和运行说明
- 为修复最终集成问题所必需的已实现模块

## 修改内容

- 更新启动脚本，使后端和 `frontend/` 可一并启动。
- 明确开发环境变量和访问地址。
- 修复最终集成验证发现的问题，不增加新功能。

## 验证与验收

```powershell
pytest -q
cd frontend
npm run build
npm test -- --run
```

启动完整系统后，浏览器验证管理端、座位端、签到、投票、服务呼叫、翻译占位、WebSocket 更新和开发座位模拟接口。

## 停止条件

任一全量测试、构建或核心演示流程失败时，本阶段不得标记完成。
